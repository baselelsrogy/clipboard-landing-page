# 📋 Clipboard Landing Page

A fully responsive landing page for a fictional product called Clipboard, which allows users to track, organize, and access copied snippets across all their devices. <br><br>
This project is inspired by modern landing page design principles and showcases clean UI, organized structure, and reusable components.

This project is part of my **Front-End learning practice**, inspired by a challenge from [Frontend Mentor](https://www.frontendmentor.io). It recreates a clean, modern **Clipboard Landing Page** using only **HTML** and **CSS**.

## 🛠️ Built With

-   HTML5 — semantic, accessible structure

-   CSS3 — responsive layout, flexbox, grid

-   Font Awesome — icons

-   Google Fonts — Bai Jamjuree

-   Custom CSS variables for theme colors and maintainability

-   Modern layout techniques (Flexbox + CSS Grid)
